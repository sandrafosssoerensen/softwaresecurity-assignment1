# AI-use declaration

AI assistance was used for:

- Discussing and documenting requirements, architecture, security controls, and the SSDLC plan.
- Helping with the initial Django implementation of components A, B, and C, including authentication, scoped JWTs, database access, the helper package, and a model stub.
- Producing setup scripts, Docker configuration, README instructions, and eight integration tests.
- Running the initial integration tests in the assistant's execution environment and drafting a record of their outcomes.
- Editing the initial report section and project documentation.
- Helping configure and troubleshoot the Jenkins pipeline, including the Windows Python path, dependency audit, Bandit scan, security gate, and test stages.
- Helping organize the vulnerability experiment evidence and update the verification documentation.

The repository owner reviewed the code, selected the experiment branches and controls, ran the local tests, created the GitHub/Jenkins credentials, and verified Jenkins build #4. AI suggestions were not treated as test evidence until they were checked against the repository and command output.
