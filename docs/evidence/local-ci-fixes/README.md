## Repeating the checks

Use Python 3.12 and a fresh virtual environment, not an environment containing
unrelated development tools. Install all three requirements files, build/install
the helper, then run:

```powershell
python scripts\check_dependencies.py --validate-only
python scripts\check_dependencies.py --report reports\dependency-approval.json
python -m pip check
python tests\test_dependency_gate.py
python tests\test_store_sql.py
python tests\test_flow.py
```

Use that environment's Python executable for every command. The vulnerable
version is expected to fail the application security checks, not the package
approval checks.

The clean local environment was created under `.runtime/ci-verification`.
Building the standalone helper wheel succeeded, but reading that generated
wheel in a later command encountered a Windows file-permission error.
For the clean local environment, `pip install --no-deps --no-build-isolation ./helper`
successfully built and installed the helper through pip's temporary wheel.
The new Jenkins run must still verify its normal explicit wheel-install step.
